# Content

The starter pack that ships with Vuurtoren: the words and the stories a new learner starts with.

```
content/
  starter/
    nl-5000.json   the 5000 most common Dutch words, with meanings and example sentences
    README.md      the format and the sources
  stories/
    A1/ A2/ B1/ B2/   one story per file
    stories.json   all stories in one bundle, as the app loads them
    README.md      the levels
  LICENSE          CC BY-SA 4.0
```

Everything here is CC BY-SA 4.0, because the dictionary and sentence sources it is built from
are. How to change or rebuild it: [For developers](../docs/dev/README.md).
