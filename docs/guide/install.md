# Install Kenning

## On your computer

1. Go to the [latest release](https://github.com/pavlohrab/Kenning/releases/latest).
2. Download the file for your computer:

   | Computer | File                                  |
   | -------- | ------------------------------------- |
   | Windows  | `.exe`                                |
   | macOS    | `.dmg` (for Apple chips or for Intel) |
   | Linux    | `.AppImage` or `.deb`                 |

   No internet on that computer? Take the file whose name starts with `Kenning_offline_`. It has
   all the Dutch data inside.

3. Open the file and install Kenning.

The apps are not signed yet, so your computer may warn you:

- **Windows:** click **More info**, then **Run anyway**.
- **macOS:** right-click the app and choose **Open**.
- **Linux (AppImage):** make the file executable (`chmod +x Kenning*.AppImage`), then run it.

Listening exercises and dictation read Dutch aloud with your system's Dutch voice. Windows and
macOS can add one in their speech settings; many Linux systems have no Dutch voice, and then
those exercises are off.

## The first start

Kenning asks one question: **Do you use Anki?**

- **No:** Kenning keeps your words and your reviews. You need nothing else.
- **Yes:** Kenning can bring your Anki decks in, or keep working with Anki. To work with Anki,
  keep Anki open with the [AnkiConnect](https://ankiweb.net/shared/info/2055492159) add-on
  (code `2055492159`).

Then add a text (paste it, give a web address, or choose a PDF or a photo) and start reading.

## Use it on more devices

- **Sync:** keep your data on every device. See [Sync](sync.md).
- **Your own server:** run Kenning for all your devices at home. See [Self-host](self-host.md).
