# Kenning 0.1.0

The first release of Kenning, an open-source Dutch reader that uses your Anki decks as the
record of the words you know. You read real texts at the right level; Kenning marks the few words
worth learning now, explains them, and adds them to Anki when you ask.

Full list of what is in it: [CHANGELOG.md](../../CHANGELOG.md#010---not-yet-tagged).

## Highlights

- **Read** anything you import (web pages, PDFs, photos, pasted text) with three modes: Read,
  Cloze and Gloss. Every word has a meaning, also when it is not in your decks.
- **Anki stays in charge.** Kenning reads your decks, writes only when you click (Add to Anki,
  Study first, Mark known), and logs every write.
- **Practice, Grammar, Courses and Exam** build on the same words: exercises with their own
  schedule, 24 grammar topics found in your own texts, study along your textbook, and A2
  inburgeringsexamen practice.
- **Optional AI** with your own key: Talk, stories at your level, sentence explanations.
- **Self-hosted, one user, all devices**: one SQLite file on your server, sign-in, backups,
  HTTPS through Caddy, Tailscale or a Cloudflare Tunnel.

## Install

Dockge (or any `docker compose`): follow [deploy/dockge/README.md](../../deploy/dockge/README.md),
five minutes. Set `KENNING_TAG=0.1.0` to stay on this release.

Plain compose from a checkout: `docker compose -f deploy/compose.yml up -d`, then open
<http://localhost:8080>. Details: [deploy/README.md](../../deploy/README.md).

Images (amd64 and arm64): `ghcr.io/<owner>/kenning-web`, `kenning-api`, `kenning-nlp`, tags
`0.1.0`, `0.1` and `latest`.

## After installing

- Settings > Advanced > **Server status** shows the version, where your data lives, whether
  sign-in is on, whether the language server has its data and whether this browser reaches Anki.
  From a shell: `scripts/doctor.sh https://your.address` (with `KENNING_TOKEN` or
  `KENNING_USER`/`KENNING_PASSWORD` when sign-in is on).
- Turn on scheduled backups (`COMPOSE_PROFILES=backup`, needs `KENNING_TOKEN` with sign-in on), or
  download one in Settings > Data & backup.

## Known limitations

- Dutch only (the code is prepared for more languages; Ukrainian is next).
- One user per installation. Browser storage mode works with one tab at a time.
- AI features are tested against fake providers; model defaults need a first live check.
- The NLP image is large (dictionary, example sentences, translation model and spaCy pipeline
  are inside, so it works offline); see the CI image report for current sizes.

## Upgrading

This is the first release. Later releases migrate the database on start; a backup made by a newer
version is refused by an older one, and a database newer than the app is never overwritten.

## Releasing (maintainers)

1. Move the `[Unreleased]` entries of CHANGELOG.md under the new version with today's date.
2. Bump `version` in the root `package.json` (and `server/nlp/pyproject.toml` +
   `kenning_nlp/__init__.py`; run `uv lock` in server/nlp).
3. Commit, then `git tag v0.1.0 && git push origin v0.1.0`. The images workflow publishes
   `0.1.0`, `0.1` and `latest`.
4. Create the GitHub release from this file.
